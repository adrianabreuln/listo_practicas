# Mi chuleta de git
- `git status`: qué ha cambiado
- `git add <fichero>`: prepara un fichero para el commit
- `git commit -m "mensaje"`: guarda lo preparado en un commit
- `git diff`: muestra cambios que aún no has preparado
- `git diff --staged`: muestra cambios ya preparados
- `git log --oneline`: muestra el historial, un commit por línea
- `git commit -am "mensaje"`: add y commit de lo ya seguido
- `git restore <fichero>`: descarta lo que no has guardado
- Atajos de teclado: mira ATAJOS.md
- `git push --force`: la mejor forma de subir cambios
